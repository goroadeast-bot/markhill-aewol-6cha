# 입지 섹션 리디자인 — 스펙

## 배경

입지 섹션이 3개 텍스트 블록 + 통짜 브로슈어 이미지 한 장으로 구성돼 있어 밋밋하다는 지적. 비주얼 컴패니언으로 두 안(에디토리얼 좌우교차 / 3열 카드)을 만들어 비교한 끝에 **A안(넘버링 + 좌우 교차)**으로 확정했다(2026-08-22).

## 변경 1 — 브로슈어 사진 6장을 개별 카드 이미지로 분리

기존 `images/6cha-location.jpg`는 3행×2열 사진이 박힌 통짜 브로슈어 이미지였다(확대해야 각 사진이 보임). 이 6장을 개별 파일로 잘라내 프로젝트에 이미 추가했다:

- `images/location-edu-1.jpg`, `images/location-edu-2.jpg` — 하귀초등학교, 귀일중학교
- `images/location-life-1.jpg`, `images/location-life-2.jpg` — 하나로마트, 애월 해안
- `images/location-view-1.jpg`, `images/location-view-2.jpg` — 단지 배치 도면, 한라산 조망(원본 브로슈어의 워터마크 포함 — 장식 요소이므로 그대로 사용)

모두 640px 폭, JPEG quality 88, 원본 브로슈어에서 흰 여백을 제외하고 타이트하게 크롭. `images/6cha-location.jpg`(통짜 브로슈어) 자체는 디스크에 남겨두되 이 섹션에서는 더 이상 참조하지 않는다(다른 곳에서도 안 쓰임 — 삭제하지 않고 보존만).

## 변경 2 — 좌우 교차 레이아웃 + 넘버링

`.location-grid`(3열 그리드)를 걷어내고, 3개 행(`.location-row`)으로 재구성한다. 각 행은 텍스트 컬럼 + 사진 2장 컬럼이 가로로 배치되며, **짝수 행(생활여건)은 좌우가 뒤바뀐다**(에디토리얼 지그재그 리듬):

1. **교육여건** — 텍스트 왼쪽, 사진(하귀초·귀일중) 오른쪽
2. **생활여건** — 사진(하나로마트·애월해안) 왼쪽, 텍스트 오른쪽 (뒤집힘)
3. **조망권** — 텍스트 왼쪽, 사진(배치도면·한라산뷰) 오른쪽

각 행 텍스트 컬럼 구성:
- 번호 라벨(`01 EDUCATION` 형식, 모노 폰트, 포인트색, 오른쪽에 얇은 선으로 이어짐)
- 항목 제목(교육여건/생활여건/조망권)
- 세부 항목 3줄(기존엔 요약 1줄만 있었음 — 브로슈어에 있던 3개 항목 전부를 불릿으로 옮긴다)
- 결론 문장(기존 요약 문장을 그대로 사용, 형광 하이라이트 + 화살표로 강조)

| 행 | 세부 항목 3줄 | 결론(기존 요약 문장 그대로) |
|---|---|---|
| 교육여건 | 하귀초·귀일중 도보 통학 가능 / 하귀초 후문 연계 학교상권 발전 가능 / 하귀초 병설유치원 인접 | 유아부터 중등까지 교육여건 매우 우수 |
| 생활여건 | 공항 및 신제주 인접 자연친화적 주거환경 지역 / 하귀·외도택지 생활권, 하나로마트 등 편의시설 인접 / 일주서로·애조로 인접 교통편의 양호 | 자연환경과 생활편의 모두 가능한 입지 |
| 조망권 | 하귀2리 주거지 중 가장 높은 위치로 조망권 우수 / 바다 및 자연조망향 동배치로 조망권 확보 / 시 외곽지역 주거지 조망권은 매우 중요한 요인 | 바다와 자연 조망이 가능한 입지 |

## 변경 3 — 구글 지도

행 3개 아래, 마크힐애월6차 주소로 구글 지도 임베드를 추가한다. 아승부동산 사이트(`d:/claude_homepage`)와 동일한 방식(`<iframe src="https://maps.google.com/maps?q=...&output=embed">`)을 그대로 재사용하고, 쿼리만 "제주특별자치도 제주시 애월읍 하귀2리 2089"로 바꾼다.

```html
<div class="location-map">
  <p class="location-map-label">MAP · 제주시 애월읍 하귀2리 2089번지</p>
  <div class="location-map-embed">
    <iframe src="https://maps.google.com/maps?q=%EC%A0%9C%EC%A3%BC%ED%8A%B9%EB%B3%84%EC%9E%90%EC%B9%98%EB%8F%84%20%EC%A0%9C%EC%A3%BC%EC%8B%9C%20%EC%95%A0%EC%9B%94%EC%9D%8D%20%ED%95%98%EA%B7%802%EB%A6%AC%202089&output=embed" loading="lazy" referrerpolicy="no-referrer-when-downgrade" title="마크힐애월6차 위치 지도"></iframe>
  </div>
</div>
```

## 변경 4 — 애니메이션

- **등장**: 3개 행 + 지도가 스크롤에 따라 순차 등장(110ms 간격, 블러+상승, 개요 섹션과 같은 이징 `cubic-bezier(0.23,1,0.32,1)`). 개요 섹션 텍스트 그룹과 동일하게 **반복**(진입/이탈마다 토글, `IntersectionObserver`, `unobserve` 없음) — 이 사이트에서 이미 확립된 패턴을 그대로 따른다.
- **호버**: 행에 마우스를 올리면 사진 2장이 위로 살짝 떠오르고(`translateY(-3px)`) 그림자가 생김, 두 번째 사진은 60ms 늦게 반응(입체감).

## 스코프 밖

- 다른 섹션(타입&가격, 프리미엄)에 같은 좌우교차 패턴 적용 — 이번 스펙은 입지 섹션 한정.
- 지도 스타일 커스터마이징(다크모드 지도 등) — 기본 Google Maps embed 그대로.
- `images/6cha-location.jpg` 삭제 — 하지 않음, 디스크에 보존.

## 테스트

- `tests/content.test.mjs`: 기존 `'location chapter states the real education/living/view facts'` 테스트를 갱신 — `images/6cha-location.jpg` 참조 검증을 6개 개별 이미지 참조 검증으로 교체, 3개 행의 세부 항목 3줄 + 결론 문장이 모두 존재하는지, 지도 iframe이 하귀2리 주소를 포함하는지 검증.
- `requiredImages` 배열에 6개 신규 이미지 추가.
- 애니메이션(순차 등장 반복, 호버)은 Playwright 라이브 검증.

## 자체 검토

- 플레이스홀더 스캔: 없음.
- 정직성: 6장 모두 브로슈어에 실제로 있던 사진을 크롭한 것 — 새로 생성한 이미지 없음. 결론 문장도 브로슈어 원문 그대로.
- 내부 일관성: 개요 섹션의 반복-등장 패턴(변경 4)과 이징 값을 그대로 재사용해 사이트 전체 애니메이션 언어 통일.
- 스코프: 입지 섹션 하나, 별도 분해 불필요.
- 모호성: 행 순서·좌우 반전 규칙(짝수 행만 뒤집힘)·이미지 파일명 매핑을 표로 명시.
