# 개요 섹션 스크롤 애니메이션 — 스펙

## 배경

브라우저 목업(비주얼 컴패니언)으로 여러 버전을 실시간 확인하며 아래 조합으로 확정했다(2026-08-22). 배치도 스케일과 캡션 등장은 Playwright로 스크롤 위치별 상태(opacity/transform)를 직접 확인해 동작을 검증했다.

## 변경 1 — 개요 텍스트(이유브로우+타이틀+표) 그룹 리빌, 반복

`#overview .container` 안의 `<p class="eyebrow">`, `<h2 class="section-title">`, `<table class="spec-table">` 3개를 `<div class="overview-intro">`로 감싼다. 개별 항목 지연 없이 **3개가 동시에** 블러(5px)+상승(14px)+페이드로 나타난다(0.7s, `cubic-bezier(0.23,1,0.32,1)`).

**반복**: 일회성(`reveal`/`is-visible` 후 unobserve)이 아니라, 섹션이 뷰포트에 들어올 때마다 나타나고 나갈 때 사라진다 — 위로 스크롤해 화면 밖으로 나가면 다시 숨겨지고, 내려오면 매번 처음부터 재생된다. `IntersectionObserver`로 구현(진입/이탈마다 클래스 토글, `unobserve` 호출 없음) — 기존 `.reveal` 시스템(일회성, `revealObserver`)과는 별개의 새 옵저버.

## 변경 2 — 배치도 스크롤 연동 스케일

`.siteplan-block`은 기존 `.reveal` 클래스를 뗀다(아래 연속 스케일 애니메이션이 그 자리를 대신하므로 일회성 페이드업과 함께 쓰면 어색하다). 이미지를 감싸는 `.siteplan-scaler` 래퍼를 새로 두고, 그 래퍼에 스크롤 위치에 연동한 `transform: scale()`을 건다.

- **0.78배**에서 시작(이미지 중심이 뷰포트 하단에 있을 때)
- 이미지 중심이 **뷰포트 정중앙**에 도달하면 **1.00배(100%)**
- 그 이후로도 계속 1.00배 유지(더 스크롤해서 중심이 위로 지나가도 100%에 고정, 다시 축소되지 않음)
- 위로 스크롤해 이미지 중심이 다시 하단으로 내려가면 배율도 다시 줄어든다 — 매 스크롤에 실시간 연동(연속값이라 "반복"이라는 개념 자체가 자연스럽게 내장됨)

진행도 계산: `p = clamp((viewportHeight - centerY) / (viewportHeight * 0.5), 0, 1)`, `scale = 0.78 + p * 0.22`.

## 변경 3 — 캡션은 배치도가 100%일 때만 별도로 등장

`<p class="siteplan-caption">101동·102동 배치도 — 하귀성당 사거리 북서측 코너부지</p>`는 변경 1의 텍스트 그룹과 무관하게, **변경 2의 진행도(`p`)가 0.995 이상**(사실상 100% 도달)일 때만 나타난다(블러+상승+페이드, 0.55s). 이 값도 매 스크롤 재계산이라 위로 스크롤해 배치도가 다시 줄어들면 캡션도 다시 숨겨진다.

## 변경 4 — 강조(형광 하이라이트) 확정

`.spec-table` 안의 셀링포인트 3개에 배경 하이라이트 + 볼드 + 포인트색을 적용한다:

| 항목 | 원문 위치 | 강조 방식 |
|---|---|---|
| `84타입 20세대` | 유형 및 규모 | `.spec-highlight` — 형광 배경 + `var(--accent)` 볼드 |
| `세대당 2.1대` | 주차대수 | `.spec-highlight` |
| `2027년 7월 입주` | 일정 | `.spec-highlight` |

그 외 고유명사(남건종합건설㈜, 하귀2리 2089번지, 마크힐센터 등)는 검정 볼드(`.spec-strong`)만, 형광 배경 없음. 나머지 설명 문구는 손대지 않는다.

형광 배경 구현: `background: linear-gradient(transparent 62%, rgba(181,102,58,0.16) 62%)` — `--accent`(#B5663A)의 저투명도 버전을 밑줄처럼 까는 방식(새 색상 토큰 추가 없음, 기존 `--accent`의 alpha만 다르게 사용).

## 반응형 / 접근성

- `prefers-reduced-motion: reduce`: 텍스트 그룹은 즉시 완전히 보이는 상태, 배치도는 스케일 애니메이션 없이 항상 100%, 캡션도 항상 보임. 전역 규칙(`css/styles.css:93-100`)이 transition/animation 지속시간은 이미 0.01ms로 죽이지만, 이 기능들의 초기 `opacity:0`/`scale(0.78)` 상태 자체는 그것만으로 가려지지 않으므로 전용 오버라이드가 필요하다(기존 히어로 애니메이션 스펙과 동일한 패턴).
- 모바일: 로직·값 변경 없음(뷰포트 높이 기준 계산이라 모바일에서도 그대로 작동).

## 스코프 밖

- 입지·타입&가격·프리미엄 섹션 — 이번 스펙은 개요 섹션 하나에 한정. 같은 패턴을 다른 섹션에 적용할지는 이후 별도로 논의.
- 배치도 사진 자체 교체 — 하지 않음.
- 기존 `.reveal` 사이트 전역 시스템 변경 — 하지 않음(개요 섹션만 별도 로직으로 분리).
