# 마크힐 애월6차 홈페이지 — 리디자인 스펙 (v2)

## 배경

2026-08-15 스펙(`2026-08-15-markhill-aewol6-design.md`)으로 8챕터 클릭 전환 구조의 사이트를 구현·완료·master에 병합했다. 실제 Chrome에서 확인한 결과, 사용자가 구조와 히어로를 다시 설계하고 싶어 해 이 문서로 변경사항을 정리한다. **이 문서는 기존 스펙을 대체하지 않고, 그 위에 얹히는 변경분만 기술한다** — 컬러 토큰, 타이포그래피, 정직성 원칙, 챕터별 콘텐츠(사실 정보)는 기존 스펙을 그대로 따른다.

## 핵심 변경 1 — 챕터 클릭 전환 → 한 페이지 연속 스크롤

기존: 상단 탭 클릭 → JS 라우터가 챕터를 통째로 hide/show (페이드 전환).
변경: **사이트 전체를 하나의 연속 스크롤 페이지로 전환.** 상단 고정 네비게이션은 챕터를 통째로 바꾸는 라우터가 아니라, 해당 섹션으로 부드럽게 스크롤 이동시키는 앵커 링크가 된다. 스크롤 중에는 현재 보고 있는 섹션에 맞춰 네비게이션 활성 표시(scroll-spy)가 갱신된다.

**상단 고정 네비게이션 — 4개 링크(순서대로):**
1. 애월6차분양 (→ 개요 섹션 상단으로 스크롤)
2. 역사
3. 갤러리
4. 문의

**페이지 전체 순서 (위→아래):**
히어로 → 애월6차분양(개요 → 입지 → 타입&가격 → 프리미엄, 서브섹션 간 경계 없이 이어서 스크롤) → 마크힐의 역사 → 갤러리 → 문의

기존 8챕터 중 "소개"는 히어로로 흡수되어 별도 챕터가 아니게 되고, 나머지 6개(개요/프리미엄/타입&가격/입지/역사/갤러리/문의)는 챕터가 아니라 한 페이지 안의 섹션이 된다. **애월6차분양 서브섹션 순서가 기존 스펙(개요→프리미엄→타입&가격→입지)에서 개요→입지→타입&가격→프리미엄으로 바뀐다** — 각 서브섹션의 콘텐츠 자체(사실/수치)는 변경 없음, 순서만 변경.

기존 챕터 단위 진입 애니메이션(스태거 리빌, `prefers-reduced-motion` 대응)은 그대로 유지 — IntersectionObserver 기반이라 연속 스크롤에도 자연스럽게 맞는다. 챕터 간 전체화면 크로스페이드(라우터 전환 애니메이션)는 라우터 제거와 함께 사라진다.

## 핵심 변경 2 — 히어로 재설계

### 레이아웃

좌우 분할, 높이는 뷰포트에 맞춰 조정(기존처럼 100vh 고정이 아니라 콘텐츠에 맞는 고정 높이 또는 최소 높이):

- **왼쪽 (약 60%)**: 실사진 풀블리드. `markhill_5차_노형/펜트하우스/KakaoTalk_20241202_164551740_12.jpg`(주방+계단 보이드 구조, 밝은 화이트/마블 톤)를 히어로 이미지로 사용. 기존 히어로에 쓰이던 `hero-living-3cha.jpg`(3차 주방)는 "마크힐의 역사" 섹션(5차 카드 또는 별도 위치)으로 용도 재배치 — **완전히 버리지 않고 히스토리 섹션에서 재사용**하는 것을 기본으로 하되, 실제 구현 시 배치가 어색하면 스킵 가능.
- **오른쪽 (약 40%)**: 사진이 아닌 `--bg`(#F8F6F2) 배경의 콘텐츠 컬럼. 텍스트를 사진 위에 얹지 않으므로 대비/가독성 문제가 원천적으로 없다.

### 오른쪽 컬럼 구성 (위→아래)

1. **헤드로우**: 워드마크 "마크힐 애월6차 분양" (헤드라인급 크기, Pretendard 900) — 좌측. 우측에 작은 필 버튼 "📞 분양상담" (탭하면 기존 전화모달 오픈, 데스크톱은 번호 표시/복사).
   - 기존 카피 "서부지역 마지막 마크힐"은 **완전히 삭제**, 다른 섹션으로 옮기지 않는다.
2. **클릭형 아이콘 카드 4개** (위→아래): 개요 / 입지 / 타입&가격 / 프리미엄. 각 카드는 라벨(한글 타이틀 + 영문 소라벨) + 오른쪽 아이콘 타일(약 30px 정사각형, 라운드 코너)로 구성. 클릭 시 해당 서브섹션으로 스무스 스크롤.
   - 카드 순서는 실제 페이지 서브섹션 순서(개요→입지→타입&가격→프리미엄)와 동일하게 맞춘다.
3. 카드 아래 여백 없이 헤드로우~카드 영역까지가 오른쪽 컬럼의 전부 — CTA 버튼/배지 등 추가 텍스트 블록 없음(카드 자체가 정보 밀도를 담당).

### 하단 스탯바 (히어로 전체 폭, 히어로 아래 가로 바)

배경 `--bg-alt`(#EFEAE2, 아이보리) + `--border` 상단 보더, 글자는 `--ink`/`--ink-subtle` (흰 글자 아님 — 밝은 배경이라 어두운 톤 사용). 4칸, 세로 구분선(`--border`):

| 하귀2리 | 84타입 20세대 | 2027.7 입주 | 4.48억~5.13억 |
|---|---|---|---|
| 제주 애월읍 | +근생 4실 | 예정 | 분양가 |

**분양가 표기는 101동/102동 전체 범위(4억4,800만~5억1,300만)를 정확히 반영** — 브레인스토밍 중 목업에 잘못 들어갔던 "4.58억"은 오기이며 최종 구현에는 반영하지 않는다(102동 최저가 4.48억 기준).

### 아이콘 이미지

4개 카드 아이콘은 사용자가 나노바나나2로 직접 생성해서 전달 예정(`icon-overview`, `icon-location`, `icon-price`, `icon-premium` — 정사각형, 가능하면 투명 배경). **파일이 도착하기 전까지는 지금 브레인스토밍 목업에서 검증한 벡터 라인아이콘 + 브랜드 그라데이션 타일(테라코타~다크 톤)로 구현**하고, 이미지가 오면 `<img>`로 간단히 교체 가능하도록 마크업을 짠다(아이콘 슬롯을 배경 이미지가 아니라 교체 가능한 `<img>` 또는 CSS 배경 하나로 통일).

## 스코프 밖 (이번 리디자인에서 다루지 않음)

- 갤러리/문의 섹션의 콘텐츠, 사진 구성 — 변경 없음, 스크롤 섹션으로 전환만.
- 역사/개요/프리미엄/타입&가격/입지 섹션 내부의 사실 콘텐츠(수치, 사진, 문구) — 변경 없음, 순서(입지↔프리미엄/타입&가격 위치)만 조정.
- 기존 스펙의 정직성 원칙, AI 이미지 사용 원칙 — 그대로 적용(아이콘은 장식 요소이므로 AI 생성 허용 대상에 해당).

## 자체 검토

- 플레이스홀더 스캔: 없음. 아이콘 이미지 파일은 사용자 제공 예정이라는 상태를 명시했고, 도착 전 대체 구현(벡터 아이콘)도 명확히 정의됨.
- 내부 일관성: 페이지 순서·네비게이션 4개 링크·히어로 카드 4개 순서가 모두 개요→입지→타입&가격→프리미엄으로 일치.
- 수치 정확성: 하단 스탯바 분양가 범위를 공식 자료 기준(4.48억~5.13억)으로 수정 — 브레인스토밍 중 오기 교정.
- 스코프: 기존 스펙 위에 얹는 리디자인 범위로 적절, 별도 분해 불필요.
- 모호성: 없음 (히어로 좌측 사진 위치가 어색할 경우의 대체 방안까지 명시).
