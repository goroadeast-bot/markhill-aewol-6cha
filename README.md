## 구성

빌드 도구 없이 동작하는 순수 정적 사이트입니다.

```
index.html        전체 페이지 (히어로 · 개요 · 입지 · 타입&가격 · 프리미엄 · 역사 · 갤러리 · 문의)
css/styles.css    디자인 토큰과 전체 스타일
js/script.js      스크롤 스파이 · 히어로 진입 애니메이션 · 갤러리/역사 모달 · 진입 팝업
js/scroll-spy.js  내비게이션 구간 판정 로직 (테스트 대상)
images/           페이지에서 사용하는 사진 (원본은 저장소에 포함하지 않음)
tests/            콘텐츠·마크업 회귀 테스트
```

`markhill_image/`, `markhill_blog/` 는 원본 사진·초안 모음이라 `.gitignore` 처리되어 있습니다.

## 로컬에서 보기

ES 모듈을 쓰므로 `file://` 로 열면 CORS 로 막힙니다. 간단한 정적 서버로 띄워주세요.

```bash
npx serve .          # 또는 python -m http.server
```

## 테스트

페이지에 실린 분양 정보(면적·가격·일정 등)가 공식 자료와 어긋나지 않도록 마크업을 검증합니다.

```bash
node --test "tests/*.test.mjs"
```
